1 同义词映射 match_meddra() L167-206

✗ 兜底编码 L277-281
未匹配到任何关键词 → LLT/PT = "其他症状"，置信度 0.60

2 严重性分级 · 四级优先级 assess_severity() L209-225
按优先级从高到低依次判定（命中即返回）： 重要医学事件 (ALT/AST≥5ULN) → 死亡 → 住院 → 危及生命 → severe  |   中度词 (影响睡眠/持续/中度) → moderate  |   轻度词 (轻微/自行缓解) → mild  |   默认 → mild
3 SAE 判定 · 六大标准 assess_sae() L228-233
逐一检查六大标准（L152-158）： ① 死亡 ② 危及生命 ③ 导致住院 ④ 残疾 ⑤ 先天性畸形 ⑥ 重要医学事件
返回：(is_sae: bool, [触发的标准名称列表])
4 预期性判断 check_expected() L236-240
对比 config.py EXPECTED_AES 中预设的 14 个预期AE（免疫相关肺炎/肝炎/结肠炎、输液反应、疲乏、发热、皮疹、瘙痒、恶心、头痛、食欲下降、贫血、血小板减少、中性粒细胞减少）
→ 非预期 + SAE = SUSAR（可疑非预期严重不良反应）
5 因果关系评估 · WHO-UMC 六级法 assess_causality() L243-270
certain (再激发阳性/免疫相关+停药缓解) → probable (SAE+停药恢复/药物相关) → possible (可能/不排除/怀疑) → unlikely (不太可能/无关/排除) → conditional (预期AE → possible) → unassessable (无法评估)
6 持久化 + 自动联动 + 返回 L292-329
6.1 INSERT INTO ae_results (19个字段: ae_id, patient_id, meddra_codes JSON, severity, sae_flag, sae_criteria JSON, expected_flag, causality, citations JSON, processing_time_ms…)
6.2 自动联动 → 调用 deviation.process_patient_visit() 检测方案偏离 (L313-322)
6.3 返回完整结果 JSON → 前端渲染编码卡片 + "生成SAE报告"按钮

3 PRR + ROR + χ² 真实统计计算 _calc_prr() L84-103  |  _calc_ror() L106-120
2×2 列联表
目标AE其他AE
目标药物ab
其他药物cd
PRR = [a/(a+b)] / [c/(c+d)]  |  χ² = (|a−E| − 0.5)² / E (Yates校正)
ROR = (a×d) / (b×c)  |  95%CI: exp(ln ROR ± 1.96×SE)
EMA阳性标准：PRR ≥ 2 且 a ≥ 3 且 χ² ≥ 4

1 SAE 提交及时性检查 check_sae_timeliness() L7-47
  • JOIN sae_reports + ae_results，过滤 report_status ≠ "submitted"
  • 计算 days_remaining = (deadline − datetime.now()).days
  • 三级状态： overdue (days < 0)  |  urgent (days ≤ 2)  |  normal (days > 2)
  • 同步计算双截止日：deadline_7day（死亡/危及生命） / deadline_15day（其他SAE）

输出：{ report_id, missing_fields[], complete: bool }
3 综合评分计算 L69-77
及时性评分 = 未超期数 / 总报告数   |   完整性评分 = 完整报告数 / 总报告数
综合评分 = 0.5 × 及时性 + 0.5 × 完整性  （总报告数为0时默认1.0）
