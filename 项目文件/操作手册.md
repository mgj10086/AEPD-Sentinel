# AE Sentinel 操作手册 V1.0

## 一、系统概述

AE Sentinel 是药物临床试验不良事件(AE)智能监测平台，覆盖 AE 编码、SAE 报告、方案偏离、信号挖掘、合规质控全流程。

**适用角色：** PV 专员 / CRA 临床监查员 / 系统管理员

---

## 二、快速启动

### 2.1 本地开发

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境（复制 .env.example 为 .env，按需修改）
#    本地开发建议 DATABASE_ENGINE=sqlite

# 3. 启动后端（端口 8000）
python run.py

# 4. 另开终端，启动前端（端口 5173）
cd frontend && npm install && npm run dev

# 5. 浏览器打开 http://localhost:5173
```

### 2.2 Docker 部署

```bash
# 全栈启动（应用 + ChromaDB）
docker-compose up -d

# 查看日志
docker-compose logs -f ae-sentinel

# 停止
docker-compose down

# 浏览器打开 http://localhost:8000
```

### 2.3 初始化测试数据

登录后进入**仪表盘**，点击 **"导入模拟测试病例"** 按钮可一键导入 10 个肺癌临床试验模拟 AE 病例。

## 四、AE 编码

### 操作步骤

1. 左侧导航点击 **"AE编码"**
2. 填写表单：
   - **患者编号**：如 `NSCLC-001`
   - **访视日期**：选择日期
   - **药物名称**：默认 `XK-001`（可在 config.py 中修改）
   - **性别 / 出生日期**：选填，用于完善 SAE 报告
   - **AE描述**：输入不良事件描述文本（必填）
   - **发生日期**：选填
3. 点击 **"AI编码分析"**
4. 右侧面板显示分析结果：
   - MedDRA PT 编码（如"头痛"、"肺炎"）
   - 严重程度（轻度/中度/重度）
   - 是否 SAE 及其判定标准
   - 预期性判断
   - 因果关系评估（WHO-UMC 6级）
   - 处理耗时

### 批量导入

在**仪表盘**页面点击 **"导入模拟测试病例"** 可批量导入 10 个病例（也可调用 API `POST /api/ae/batch`）。

### 查看记录

页面底部表格展示所有历史 AE 编码记录，支持分页和筛选。SAE 标记为 **"是"** 的行可点击 **"生成SAE"** 一键生成报告。

## 五、SAE 报告

### 生成报告

1. 在 **AE编码** 页面，找到标记为 SAE 的记录
2. 点击 **"生成SAE"** 按钮
3. 系统自动生成 CIOMS-I 格式报告，7 天内截止

### 查看与编辑

1. 左侧导航点击 **"SAE报告"**
2. 列表展示所有 SAE 报告（报告编号/患者/状态/截止日期）
3. 支持按状态（draft/submitted）筛选
4. 可更新报告字段：CIOMS-I 字段、因果关系评估、报告状态

### 提交报告

SAE 报告编写完成后：
1. 点击报告进入详情
2. 调用 **提交接口** `POST /api/saereport/{report_id}/submit`
3. 状态从 `draft` 变为 `submitted`

### 导出报告

支持三种格式导出（`GET /api/saereport/{report_id}/export?format=docx|json|pdf`）。

### 合规时限

- **24 小时**：NMPA GCP 要求的快速报告时限（获知 SAE 后）
- **7 天**：死亡/危及生命的 SAE 详细报告
- **15 天**：其他 SAE 详细报告

## 六、方案偏离

### 偏离规则

系统内置 7 条默认偏离规则（PD-001 ~ PD-007）：

| 编号 | 规则 | 触发条件 |
|------|------|---------|
| PD-001 | 访视超窗 | 实际访视日期超出计划 ±3 天 |
| PD-002 | 访视未做 | 计划访视日期已过但无记录 |
| PD-003 | 用药依从性不足 | 实际剂量 < 期望剂量的 80%（需接入用药数据） |
| PD-004 | 禁止用药使用 | 合并用药中包含方案禁止药物 |
| PD-005 | 检查缺失 | 必做安全性检查未完成 |
| PD-006 | 入组标准不符 | 入排标准未满足 |
| PD-007 | 排除标准违反 | 排除标准被违反 |

### 操作

1. 左侧导航点击 **"方案偏离"**
2. 查看偏离列表（按严重度/状态筛选）
3. 处理偏离：填写**解决说明 + 处理措施**，状态变为 `resolved`
4. 系统在每次 AE 编码时自动检测对应患者的方案偏离

## 七、信号挖掘

### 触发分析

1. 左侧导航点击 **"信号挖掘"**
2. 点击触发分析（或调用 API `POST /api/signals/trigger`）
3. 系统在后台统计 AE 数据，按 10 个器官系统分类计算信号：
   - 统计方法：PRR（比例报告比）+ ROR（报告优势比）+ Chi² 检验
   - EMA 标准：PRR≥2, 事件数≥3, χ²≥4 → 阳性信号
4. 查看信号列表和详情（信号名称/事件数/发生率/背景率/统计检验/建议措施）

### PubMed 文献（需配置）

配置 `NCBI_API_KEY` 环境变量后可接入真实 PubMed 文献检索。未配置时返回提示信息。

---

## 八、合规质控

1. 左侧导航点击 **"合规质控"**
2. 查看：
   - **SAE 及时性**：每份报告的截止日状态（正常/即将超期/已超期）
   - **字段完整性**：CIOMS-I 报告缺失字段检查
   - **综合评分** = 及时性×50% + 完整性×50%
3. 支持周期筛选（weekly/monthly）

---

## 九、知识库管理（管理员）

### 上传文档

1. 左侧导航点击 **"知识库"**
2. 点击上传，选择文件（支持 `.md` `.csv` `.txt` `.pdf` `.json`，最大 10MB）
3. 系统自动向量化存入 ChromaDB

### 搜索知识

调用 API `GET /api/admin/knowledge/search?query=关键词` 进行语义检索。

### 查看与管理

知识库列表支持按类型筛选、查看状态、删除。

## 十、审计日志（管理员）

1. 左侧导航点击 **"审计日志"**
