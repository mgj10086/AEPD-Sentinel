**一、概述**

AE Sentinel（药物临床试验不良事件智能监测平台）是一个基于 Agentic RAG与多智能体协作架构的临床安全性监测系统。本文档详细描述了平台前后端交互的所有 API 接口，涵盖认证、AE编码与严重性初筛、SAE报告生成、方案偏离识别与预警、安全性信号挖掘、合规与质控、知识库管理及审计日志等核心模块。

> • 基础 URL：http://localhost:8000/api
>
> • 所有请求/响应均使用 JSON 格式
>
> • 认证方式：Bearer Token（Mock模式，用于开发测试）
>
> • 字符编码：UTF-8
>
> • 时间格式：ISO 8601（如 2026-06-06T10:00:00Z）

**三、错误码定义**

系统采用两类错误码体系：HTTP 状态码用于网络层错误，业务错误码用于应用层逻辑判断。业务错误码对应的 HTTP 状态码仍为 200，客户端需根据 code 字段判断实际业务结果。

**3.1 HTTP 状态码**

  ------------------------------------------------------
  **错误码**   **HTTP状态码**   **说明**
  ------------ ---------------- ------------------------
  200          200              成功

  400          400              请求参数错误

  401          401              未授权/Token过期

  403          403              权限不足

  404          404              资源不存在

  409          409              数据冲突（如重复提交）

  422          422              业务校验失败

  500          500              服务器内部错误
  ------------------------------------------------------

**3.2 业务错误码**

  ----------------------------------------------
  **错误码**   **模块**   **说明**
  ------------ ---------- ----------------------
  10001        AE编码     AE文本为空

  10002        AE编码     MedDRA编码未找到匹配

  10003        AE编码     SAE判定结果不确定

  10004        AE编码     批量处理部分失败

  20001        方案偏离   方案偏离规则不存在

  20002        方案偏离   访视数据格式错误

  30001        SAE报告    SAE报告字段不完整

  30002        SAE报告    CIOMS-I模板渲染失败

  40001        信号挖掘   PubMed检索无结果

  40002        信号挖掘   信号分析计算异常

  50001        系统基础   LLM服务不可用

  50002        系统基础   向量数据库连接失败

  50003        系统基础   知识库索引构建失败
  ----------------------------------------------

**五、智能体1：AE编码与严重性初筛**

该智能体负责对临床试验中报告的不良事件（AE）进行 MedDRA 编码、严重性评估、SAE 判定及因果关系初步分析。支持单条和批量两种处理模式。

**5.1 单条AE处理**

> **POST /api/ae/process** 单条AE文本编码与严重性初筛

**请求参数**

  -----------------------------------------------------------------------
  **字段名**   **类型**   **必填**   **说明**
  ------------ ---------- ---------- ------------------------------------
  ae_text      string     是         AE描述文本（自由文本或结构化数据）

  patient_id   string     是         患者唯一标识

  visit_date   string     是         访视日期，格式：YYYY-MM-DD

  drug_name    string     是         怀疑药物名称
  -----------------------------------------------------------------------

**请求示例**

> **JSON:**
>
> {
>
> \"ae_text\": \"患者出现严重皮疑，全身散在红方，伴瘩痒\",
>
> \"patient_id\": \"P001\",
>
> \"visit_date\": \"2026-06-01\",
>
> \"drug_name\": \"实验药物A\"
>
> }

**响应字段**

  ---------------------------------------------------------------------------------------------------------------
  **字段名**                    **类型**          **说明**
  ----------------------------- ----------------- ---------------------------------------------------------------
  ae_id                         string            AE记录唯一标识

  meddra_codes                  array             MedDRA编码结果列表

  meddra_codes\[\].llt_code     string            低级术语编码

  meddra_codes\[\].llt_name     string            低级术语名称

  meddra_codes\[\].pt_code      string            首选术语编码

  meddra_codes\[\].pt_name      string            首选术语名称

  meddra_codes\[\].soc_code     string            系统器官分类编码

  meddra_codes\[\].soc_name     string            系统器官分类名称

  meddra_codes\[\].confidence   float             编码置信度（0-1）

  severity                      string            严重性等级：mild \| moderate \| severe

  sae_flag                      boolean           是否为严重不良事件（SAE）

  sae_criteria                  array\[string\]   判定为SAE的标准列表

  expected_flag                 boolean           是否为预期不良反应

  causality_tentative           string            初步因果关系判断：possible \| probable \| unlikely \| related

  citations                     array\[string\]   参考文献引用

  processing_time_ms            integer           处理耗时（毫秒）

**六、智能体3：SAE报告生成**

该智能体负责根据 AE 编码结果自动生成符合 CIOMS-I 标准的严重不良事件（SAE）报告，包含因果关系评估、相似药物安全性信息及报告导出功能。

**6.1 生成SAE报告**

> **POST /api/saereport/generate** 根据AE记录生成SAE报告

**请求参数**

  ------------------------------------------------------
  **字段名**      **类型**   **必填**   **说明**
  --------------- ---------- ---------- ----------------
  ae_id           string     是         关联的AE记录ID

  reporter_name   string     是         报告人姓名

  reporter_org    string     是         报告人所属机构
  ------------------------------------------------------

**响应字段**

  ----------------------------------------------------------------------------
  **字段名**             **类型**   **说明**
  ---------------------- ---------- ------------------------------------------
  report_id              string     SAE报告唯一标识

  ae_id                  string     关联的AE记录ID

  cioms_fields           object     CIOMS-I报告字段集合（含20+字段）

  causality_assessment   string     因果关系评估结果

  similar_drug_safety    string     相似药物安全性信息摘要

  report_status          string     报告状态：draft \| reviewed \| submitted

  created_at             string     报告创建时间（ISO 8601）

  deadline               string     报告截止日期（ISO 8601）
  ----------------------------------------------------------------------------

**CIOMS-I 报告字段（cioms_fields）**

  ---------------------------------------------------------------------------------
  **字段名**               **类型**   **说明**
  ------------------------ ---------- ---------------------------------------------
  patient_initials         string     患者姓名首字母

  patient_dob              string     患者出生日期

  patient_gender           string     患者性别

  ae_description           string     AE描述

  ae_start_date            string     AE发生日期

  ae_end_date              string     AE结束日期

  ae_serious               boolean    是否严重

  ae_outcome               string     转归：recovered \| ongoing \| fatal \| etc.

  suspect_drug_name        string     怀疑药物名称

  suspect_drug_dose        string     药物剂量

  suspect_drug_dates       string     用药日期范围

  concomitant_drugs        array      合并用药列表

  reporter_qualification   string     报告人资质

  study_number             string     研究编号

  sponsor                  string     申办方

  narrative                string     事件叙述

  causality_method         string     因果关系评估方法

  causality_score          string     因果关系评分

  dechallenge              string     去激发结果

  rechallenge              string     再激发结果
  ---------------------------------------------------------------------------------

**十、知识库管理**

知识库管理接口用于上传、查询和管理平台所需的各类知识文档，包括 MedDRA 词典、临床方案、法规文件、文献资料及报告模板。上传的文档将被自动解析、分块并建立向量索引，供 Agentic RAG 检索使用。

**10.1 上传知识文档**

**请求参数**

  ----------------------------------------------------------------------------------------------------------
  **字段名**    **类型**   **必填**   **说明**
  ------------- ---------- ---------- ----------------------------------------------------------------------
  file          File       是         上传文件（支持 PDF、DOCX、TXT、XLSX）

  type          string     是         文档类型：meddra \| protocol \| regulation \| literature \| template

  description   string     否         文档描述说明
  ----------------------------------------------------------------------------------------------------------

**响应字段**

  ------------------------------------------------------
  **字段名**   **类型**   **说明**
  ------------ ---------- ------------------------------
  task_id      string     异步任务ID，用于查询处理进度

  status       string     任务状态：processing

  file_name    string     上传文件名
  ------------------------------------------------------

**路径参数**

  -----------------------------------------------
  **参数名**   **类型**   **必填**   **说明**
  ------------ ---------- ---------- ------------
  task_id      string     是         上传任务ID

  -----------------------------------------------------------------
  **字段名**   **类型**   **说明**

  message      string     状态描述信息
  -----------------------------------------------------------------

**十一、审计日志**

审计日志接口用于查询系统操作日志，支持按智能体类型、操作类型、时间范围和用户等维度进行筛选查询。

**11.1 查询审计日志**

> **GET /api/admin/audit-logs** 分页查询系统审计日志

**查询参数**

  ----------------------------------------------------------------------------------------------------------------
  **参数名**   **类型**   **必填**   **说明**
  ------------ ---------- ---------- -----------------------------------------------------------------------------
  page         integer    否         页码，默认1

  page_size    integer    否         每页条数，默认20

  agent_type   string     否         智能体类型筛选：ae_coder \| deviation \| sae_report \| signal \| compliance

  action       string     否         操作类型筛选：create \| update \| delete \| export

  date_from    string     否         开始日期（YYYY-MM-DD）

  date_to      string     否         结束日期（YYYY-MM-DD）

  user_id      string     否         按操作用户筛选
  ----------------------------------------------------------------------------------------------------------------

**响应**

返回分页格式，items 为审计日志列表，每条记录包含：log_id、user_id、agent_type、action、resource_id、detail、created_at 等字段。
