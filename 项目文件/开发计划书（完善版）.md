**一、任务理解与目标**

本项目旨在构建一个基于 Agentic RAG（智能检索增强生成）与多智能体协作的药物临床试验安全监测平台，覆盖不良事件（AE）智能编码、方案偏离预警、严重不良事件（SAE）自动报告、安全性信号挖掘、合规质控五大核心功能。

本文档是对原始开发计划书的完善版，重点补充了以下内容：

- 具体列出每项数据的获取方式并验证可行性

- 列出开发者需要提供的信息和配合操作

- 检查缺失工具并提出解决方案

- 明确前端技术方案（HTML单文件、简约浅色风格），修改为vue3，运行命令为npm run dev

- 提出完善计划书的参考建议

**4.2 缺失工具解决方案**

**① Redis（未安装）**

用途：实时方案偏离推送（WebSocket）、消息队列

解决方案：

- 方案A（推荐）：通过 Docker 安装 Redis：docker run -d \--name redis -p 6379:6379 redis:latest

- 方案B：直接下载 Windows 版 Redis 安装包

- 方案C（简化方案）：若前端为 HTML 单文件，可用定时轮询（Polling）替代 WebSocket，完全去掉 Redis 依赖

**② Nginx（未安装）**

用途：原计划用于前端静态文件服务

解决方案：

**✅ 已解决 ------ 根据前端要求，改为 HTML 单文件可直接在浏览器中打开，无需 Nginx。后端 API 服务由 FastAPI 自带的 Uvicorn 提供，亦无需 Nginx 反向代理。**

**③ GPU 显存不足（2GB）**

问题：原计划推荐 Qwen-14B（需 24GB 显存），当前 GPU 仅 2GB，无法运行大模型

解决方案：

- 方案A（推荐）：使用 Qwen2.5-7B-Instruct INT4 量化版（约4-5GB），通过 Ollama 以 CPU 推理模式运行，15.7GB 内存可支撑

- 方案B：使用 Qwen2.5-3B-Instruct（约2GB），可利用 GPU 加速，但效果有所降低

- 方案C：使用智谱 API（GLM-4）作为云端 LLM，数据脱敏后可安全使用

- 向量嵌入模型 bge-large-zh-v1.5（1.2GB）可在当前 GPU 上运行，不受影响

**④ Python 依赖包未安装**

解决方案：一键安装命令：

**pip install langchain chromadb fastapi uvicorn transformers torch sentence-transformers biopython apscheduler jinja2 python-docx pymysql redis**

注：若仅 CPU 推理，安装 torch 时使用 CPU 版本可节省空间：pip install torch \--index-url https://download.pytorch.org/whl/cpu
