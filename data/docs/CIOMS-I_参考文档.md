# CIOMS-I 严重不良事件报告表参考

## 来源
CIOMS 工作组 VI 报告《临床试验安全性信息管理》（中文翻译版）
https://cioms.ch/publications/product/chinese-translation-management-of-safety-information-from-clinical-trials/

## CIOMS-I 表格核心字段

### A. 患者信息
| 字段 | 说明 |
|------|------|
| Patient Initials | 患者姓名首字母（脱敏后） |
| Date of Birth | 出生日期 |
| Gender | 性别 |
| Weight/Height | 体重/身高（可选） |

### B. 不良事件信息
| 字段 | 说明 |
|------|------|
| AE Description | 不良事件描述（诊断或症状） |
| AE Start Date | AE 开始日期 |
| AE End Date | AE 结束日期（如适用） |
| Seriousness Criteria | 严重性标准：死亡/危及生命/住院/延长住院/残疾/先天异常/重要医学事件 |
| Outcome | 转归：恢复/恢复中/未恢复/恢复伴后遗症/死亡/未知 |

### C. 可疑药物信息
| 字段 | 说明 |
|------|------|
| Suspect Drug Name | 可疑药物名称（通用名+商品名） |
| Dose/Frequency/Route | 剂量/频次/给药途径 |
| Start Date | 用药开始日期 |
| End Date | 用药结束日期 |
| Indication | 适应症 |

### D. 合并用药（Concomitant Drugs）
| 字段 | 说明 |
|------|------|
| Drug Name | 药物名称 |
| Dose/Route | 剂量/途径 |
| Start/End Date | 使用日期 |
| Indication | 适应症 |

### E. 因果关系评估
| 字段 | 说明 |
|------|------|
| Causality Method | 评估方法（WHO-UMC, Naranjo, etc.） |
| Causality Score | 评估结果 |
| Dechallenge | 停药后反应（阳性/阴性/不适用） |
| Rechallenge | 再用药反应（阳性/阴性/不适用） |

### F. 报告人信息
| 字段 | 说明 |
|------|------|
| Reporter Name | 报告人姓名 |
| Reporter Qualification | 报告人资质 |
| Reporter Organization | 报告人所属机构 |
| Report Date | 报告日期 |

### G. 事件叙述（Narrative）
包含患者医疗史、AE 发生经过、治疗措施、实验室检查结果等综合描述。

### H. 申办方信息
| 字段 | 说明 |
|------|------|
| Sponsor Name | 申办方名称 |
| Study Number | 研究编号 |
| Country | 国家 |

## SAE 报告递交时限
- 致死或危及生命的 SAE：**7 个日历日**内首次报告
- 其他 SAE：**15 个日历日**内首次报告
- 随访报告：根据事件进展及时提交

## 参考标准
- ICH E2A: Clinical Safety Data Management
- ICH E2B(R3): Electronic Transmission of ICSRs
- CIOMS Working Group VI: Management of Safety Information from Clinical Trials
